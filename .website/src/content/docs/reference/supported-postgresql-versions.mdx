SQLStreams runs on PostgreSQL 15, 16, 17, and 18. The supported set is the
majors the PostgreSQL community still supports, so a major leaves the list in
the first release after the community drops it. 14 reaches end of life in
November 2026 and was never on the list; 15 follows in November 2027.

Any minor of a listed major is supported. The table records the minor a
verification actually ran on, which is the evidence behind the row and
nothing more.

Nothing in the SQL pins a floor. The features in use (`SKIP LOCKED`, range
partitioning, `gen_random_uuid()`) all predate 15. The floor is the support
window and nothing else.

## What is verified

Every push to main and every release tag runs the integration suite against
each listed major with the race detector on. The suite's subject is the lock
manager and MVCC: claims, leases, the snapshot fence, cursors, compaction,
partitions. The signal cases (what a killed or signalled process leaves
behind) run by hand on the oldest majors at a release checkpoint.

| Source | 15 | 16 | 17 | 18 | Notes |
| ------ | -- | -- | -- | -- | ----- |
| 15a2dde5 (main, after v0.1.5) | 15.19 | 16.15 | 17.11 | 18.6 | 103 integration tests in 9 packages passed on each, race detector on, 2026-09-14. All four signal cases passed on 15.19 and 16.15. |

A release adds its row at its checkpoint. The initial investigation before
this table (the same four minors, 102 tests) ran on a snapshot that predates
the current retry code and is not listed.

## What the promise covers

Three different things get called compatibility here:

- Server version, this page - the library's SQL runs correctly on each listed
  major. That is the whole promise.
- A PostgreSQL major upgrade - yours to run, with `pg_upgrade` or dump and
  restore. SQLStreams's tables are plain tables and range partitions with no
  extensions or custom types, so they move like any other table. Not tested
  here.
- A SQLStreams schema upgrade - the migration registry and its minimum
  compatible version. See
  [Upgrades & Migrations](/guides/migrations/) for the gate and the release
  compatibility table.
